# 👋 I'm Alex

Software engineer and product designer: Python execution environments, developer tooling, AI products. London.

Since 2017 the sole builder of [Juno](https://juno.sh), a Python and Jupyter IDE for iOS. Juno offers a complete Python and Jupyter environment inside the iOS sandbox that runs entirely on-device. It comes with CPython and Jupyter runtimes, the full scientific and data stack, debug tools, a package manager with a dependency resolver, and an AI coding assistant.

Most of the open-source side of that work lives in the [rationalmatter](https://github.com/rationalmatter) organisation: the scientific stack, Jupyter and other C-extension packages patched and recompiled for a platform with no runtime linker or subprocesses (see `embedded-components.*`), and the editor and terminal components Juno is built on.

Outside of Juno: iOS domain architect at Kindred Group (2015–21), engineering manager at 44pixels (2024–26), and C/C++ work going back to 2008. I studied machine learning on my own in 2015–18; some of the pinned repos and one paper ([Pattern Recognition and Image Analysis, 2018](https://doi.org/10.1134/S1054661818010182)) are from that period.

I like figuring things out and often move into unfamiliar domains to take on whatever hard problems I find there. I like to design what I build.
